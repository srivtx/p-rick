The charter
method · four tests

Research first, products later. Every paper verifies its gap, grades its evidence, and regenerates its figures from code — or it does not ship.

The bar

four tests, all mandatory The method →
test 01

Gap verified

Before anything is proposed, the landscape is searched for incumbents — products, papers, standards. A gap only counts if the search comes back empty.

test 02

Large audience

The missing thing must matter to many: a category with mass use, not a niche tool or a wrapper around an existing capability.

test 03

No toy output

Excluded by charter: test suites, deterministic wrappers, anything an AI obsolete. What ships is theory, architecture, or a validated harness.

test 04

Honest grading

Every paper grades its own evidence — claims are marked verified, estimation, or verification-queued. Constants are derived laws or labeled configuration-specific.

About the program

p-rick is an independent research program on missing software. It publishes working papers the way a lab does: gap verification first, formal models second, evaluation designs third — and only then, if ever, products. The program’s unit of work is the paper; each one states its gap as a falsifiable claim with named incumbents and honest evidence grading, and each ships with a companion essay written for the practitioner the paper is aimed at.

The program arc runs from specification (series I–V: the missing systems and their quiet premises) to derivation (series VI–VII: laws with validation harnesses, figures that regenerate from code in the repository). The bar every paper must clear — and the exclusions the program will never ship — are on the method page.

Everything is open: papers as markdown, PDFs typeset from them, simulation harnesses and figure code in the repository, and a work ledger (agents.md) that records every research session. Papers are licensed CC BY 4.0; code is MIT. Cite from the BibTeX block, subscribe to the RSS feed for essays, and read the work at github.com/srivtx/p-rick.

The program’s name is a private joke about friction; the work is serious. Research first; products later — if a gap survives its paper, building it is someone else’s very good business.
